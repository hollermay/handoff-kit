How it works

Runs on your machine. Python 3, no dependencies, nothing uploaded.

Type /handoff

The skill reads your saved chat and your git repo, and drops the noise.

Get HANDOFF.md

Goal, decisions with reasons, current state, results, open threads and a suggested first task.

Paste it anywhere

Paste it into a new chat, or upload the file. The other model never needs your tools or memory.

Install

Works in Claude Code and Codex. For ChatGPT or Gemini, use the exported file.

Install the skill (it asks which tools to add it to; add -g to install for all projects)

npx skills add hollermay/handoff-kit --skill handoff

Or from a clone, for Claude Code and Codex

git clone https://github.com/hollermay/handoff-kit
cd handoff-kit
python3 -m handoff install-skill --to both

Then open a new session and type

/handoff

Or use the command line alone

python3 -m handoff export --from claude --tools

Add --tools to include tool calls and their results, or --full for everything with no limits.

Privacy and limits

  • Local only. Nothing is uploaded or sent anywhere. The skill needs no account or API key.
  • Secrets are removed by pattern (API keys, tokens, passwords, private keys). It can miss unusual ones, so skim the file before sharing, especially with --tools or --full.
  • Long chats are trimmed. By default it keeps the start and the most recent part, up to 60,000 characters, and tells you how many turns were dropped.
  • Git snapshot is short. It uses a diffstat, not the full diff.
  • Gemini's logs.json only holds your own prompts, not the replies.
